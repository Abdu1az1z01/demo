ZETTA BILLING — система муниципальной инспекции коммунальных услуг
===================================================================

КАК ЗАПУСТИТЬ (Windows)
1. Распакуйте архив ZettaBilling-windows.zip в любую папку
   (например, на Рабочий стол). Запускать прямо из архива нельзя.
2. Откройте папку ZettaBilling и дважды нажмите ZettaBilling.exe.
3. Если Windows покажет синее окно «Система Windows защитила ваш компьютер» —
   нажмите «Подробнее», затем «Выполнить в любом случае».
   (Так бывает с любой программой без платной цифровой подписи.)
4. Откроется чёрное окно программы, а через 10–20 секунд — сайт в браузере.
   Если браузер не открылся, откройте вручную: http://localhost:8080

КАК ОСТАНОВИТЬ
  Закройте чёрное окно программы. Пока оно открыто — сайт работает.

ГДЕ ХРАНЯТСЯ ДАННЫЕ
  C:\Users\<ваше имя>\ZettaBilling\data
  Данные сохраняются между запусками. Чтобы начать с чистой базы,
  закройте программу и удалите эту папку.

ЕСЛИ НЕ ЗАПУСКАЕТСЯ
  «Port 8080 was already in use» — программа уже запущена (или другая
  программа заняла порт 8080). Закройте второе окно ZettaBilling.
